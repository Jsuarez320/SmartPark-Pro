# Branding

## Identidad visual

- Producto: SmartPark Pro, sistema de gestión de parqueadero (app de escritorio Electron).
- Logotipo: caja cuadrada cyan con "SP" (32px en header; 64px con ícono `Car` + sombra brand/20 en login). Sin logotipo gráfico complejo.
- Leyenda de recibo impreso: "SmartPark Pro — Control e Ingeniería de Parqueo".

## Personalidad

- Orden, control y eficiencia.
- Técnico-profesional: transmite "producto de software", no marca física de estacionamiento.

## Estilo

- Minimalista-empresarial-técnico, moderno (nivel dashboard SaaS 2023–2026).
- Lenguaje visual shadcn/ui + Tailwind: radios generosos, bordes slate, sombras sutiles, transiciones de hover.
- Paleta cyan + slate, baja saturación, mucho aire. Sobrio, sin sobrecarga.
- Base visual fuerte en la forma; el contenido de varias pantallas aún es placeholder.

## Tono (copy)

- Formal y operativo, en español (es-CO).
- Ejemplos: "Inicie sesión para continuar", "Registre un nuevo vehículo que ingresa al parqueadero".
- Descripciones cortas en subtítulos `text-muted`; acción directa en botones ("Registrar Entrada", "Cobrar", "Cerrar Caja").

## Identidad técnica

- Placa de vehículo: `font-mono tracking-widest uppercase`.
- Recibo: formato termal de 80mm, `Courier New`.
- Badges de estado con punto de color.
